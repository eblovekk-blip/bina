Google 계정 연동 (OAuth)

Google Client ID를 넣고 로그인하면 시트와 연결돼요

본인 Google 계정으로 로그인하면, 그 계정이 열 수 있는 스프레드시트만 읽고 써요(권한 범위: 스프레드시트 편집). 로그인 정보는 이 브라우저에만 잠시(약 1시간) 보관되고, 인터넷이 끊기거나 로그인이 풀리면 기록은 브라우저에 쌓아 두었다가 다시 연결될 때 올라가요.

Client ID는 Google Cloud Console → API 및 서비스 → 사용자 인증 정보에서 OAuth 클라이언트 ID(웹 애플리케이션)로 만들고, 승인된 자바스크립트 원본에 https://eblovekk-blip.github.io 를 넣으면 발급돼요. Google Sheets API도 함께 사용 설정해야 해요.
